# Installation

Read this when installing self-improvement or its CI-only counterpart.

## Interactive Agents

```bash
gh skill install pskoett/pskoett-skills self-improvement
```

## CI-Only Execution

```bash
gh skill install pskoett/pskoett-skills self-improvement-ci
```

## Agent Skills CLI Fallback

```bash
npx skills add pskoett/pskoett-skills/skills/self-improvement
npx skills add pskoett/pskoett-skills/skills/self-improvement-ci
```

For optional Claude Code, Codex CLI, or GitHub Copilot activation, read
[hooks-setup.md](hooks-setup.md). Installing the skill does not configure hooks.
